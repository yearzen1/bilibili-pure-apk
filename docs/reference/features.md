# 功能清单

## 功能

| 功能 | 说明 |
| --- | --- |
| 视频搜索 | 5 种排序（综合/播放/发布/弹幕/收藏）、分页加载、左右滑动切换排序、搜索历史持久化 |
| 视频详情 | 多 P 选集、描述展开/折叠、发布日期、封面、收藏按钮（仅登录显示） |
| 合集 | 详情页合集列表（BottomSheet、分页、排序） |
| 原生播放 | ExoPlayer 播放，全屏（传感器横屏）、沉浸式状态栏 |
| 手势控制 | 双击播放/暂停、长按倍速（松手恢复）、左侧调亮度、右侧调音量 |
| 速度控制 | 弹出菜单 0.5x–2.0x；按钮倍速与长按倍速互不影响 |
| 画质选择 | DASH（fnval=16）多画质流，播放器内 PopupMenu 切换 |
| 字幕 | B 站 AI 字幕与 CC 字幕，可拖拽定位，位置持久化 |
| 播放器状态栏 | 全屏顶部显示网络类型（WiFi/流量）与电量 |
| 屏幕常亮 | 设置项控制播放/缓冲期间不自动熄屏 |
| 观看历史 | 分 P 进度显示、30 秒心跳上报、离线补传、服务端搜索（标题 + UP 主名） |
| 我的收藏 | 收藏夹列表 → 视频列表两级浏览、分页、收藏夹增删改 |
| 关注 UP 主 | 详情页与频道页关注/取关，`x/relation` 直查关注状态 |
| 关注列表 | 个人中心入口、分页加载、横向滑动切排序 |
| UP 主频道 | 点击 UP 主名进入频道页，查看该 UP 主视频（分页） |
| 评论系统 | 游标分页、展开/收起回复、置顶/点赞/排序 |
| 评论增强 | GIF 动画、B 站自定义表情内联、图片查看器（缩放 + 原图保存） |
| 笔记查看 | 评论区识别笔记链接，应用内 WebView 渲染全文 |
| 登录 | 扫码 / 短信 / 密码三标签页，极验 Geetest 验证码 |
| 视频下载 | 渐进式 MP4、前台服务通知、暂停/继续/删除、应用私有目录免权限 |
| 我的下载 | 列表展示封面/标题/画质/大小/进度，支持本地播放 |
| 个人中心 | 登录状态（头像/昵称/UID）、我的下载/设置入口、退出登录 |
| 深色模式 | 跟随系统 / 浅色 / 深色 |
| 应用内更新 | GitHub 版本比对、下载安装、复用已下载安装包 |
| 用户反馈 | 邮件发送 Bug 反馈与功能建议，自动附带版本与设备信息 |

## 设置项

| 分组 | 设置 | 默认值 | 存储 key | 说明 |
| --- | --- | --- | --- | --- |
| 外观设置 | 深色模式 | 跟随系统 | `theme_mode` | `0` 跟随系统 / `1` 浅色 / `2` 深色 |
| 播放设置 | 播放时屏幕常亮 | 关闭 | `keep_screen_on_while_playing` | 仅在播放/缓冲期间保持常亮，暂停或退出即恢复系统息屏 |
| 网络设置 | 仅 WiFi 播放视频 | 开启 | `wifi_only_playback` | 移动网络下不播放并 Toast 提示 |
| 网络设置 | 仅 WiFi 下载视频 | 开启 | `wifi_only_download` | 移动网络下不下载 |
| 关于 | 检查更新 | — | `update_prompted_tag` | GitHub release 版本比对与下载 |
| 关于 | 用户反馈 | — | — | 组装 mailto 链接，业务逻辑见 `FeedbackEmail` |

所有设置存于 SharedPreferences 文件 `bili_settings`，读写入口统一在 `AppSettings`。

## 播放器内控件

| 控件 | 位置 | 行为 |
| --- | --- | --- |
| 画质 | 控制栏注入按钮 | PopupMenu 列出 `accept_quality`，切换后重建 MediaItem 并 seek 回原进度 |
| 倍速 | 控制栏注入按钮 | PopupMenu 0.5x–2.0x；长按临时倍速，松手恢复 |
| 字幕 | 控制栏注入按钮 | 选择轨道/关闭；字幕层可拖拽，坐标持久化 |
| 全屏 | 控制栏按钮 | 切换 `SCREEN_ORIENTATION_SENSOR_LANDSCAPE` 与沉浸式 |
